**1. Define JSX.**

JSX (JavaScript XML) is a syntax extension for JavaScript that allows developers to write HTML-like code inside JavaScript. It makes React code easier to read and write.



**2. Explain about ECMAScript.**

ECMAScript (ES) is the standard specification for JavaScript. It introduces new features such as `let`, `const`, arrow functions, classes, modules, and template literals, making JavaScript more powerful and easier to use.



**3. Explain `React.createElement()`.**

`React.createElement()` is a React method used to create React elements. JSX is internally converted into `React.createElement()` calls before rendering.



**4. Explain how to create React nodes with JSX.**

React nodes are created by writing JSX syntax. JSX allows developers to define HTML-like elements, which React converts into React elements and displays in the browser.



**5. Define how to render JSX to the DOM.**

JSX is rendered to the DOM using React's rendering method. The root component is rendered into the HTML page, and React updates the DOM whenever the component data changes.



**6. Explain how to use JavaScript expressions in JSX.**

JavaScript expressions can be used inside JSX by enclosing them within curly braces `{}`. This allows variables, calculations, and function calls to be displayed dynamically.



**7. Explain how to use inline CSS in JSX.**

Inline CSS in JSX is applied using the `style` attribute with a JavaScript object. CSS property names are written in camelCase, and values are assigned as object properties.
