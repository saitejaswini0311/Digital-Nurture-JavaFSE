**1. Define SPA and its benefits.**

SPA (Single Page Application) is a web application that loads a single HTML page and updates content dynamically without reloading the entire page. Its benefits include faster performance, a better user experience, and reduced server requests.



**2. Define React and identify its working.**

React is a JavaScript library used to build user interfaces. It works by creating reusable components and updating only the changed parts of a webpage using the Virtual DOM.



**3. Identify the differences between SPA and MPA.**



A Single Page Application (SPA)\*\* loads only one web page initially and updates the content dynamically without reloading the entire page. This provides faster navigation and a smoother user experience. SPAs are commonly developed using JavaScript frameworks and libraries such as React.



A Multi-Page Application (MPA) loads a new web page from the server whenever the user navigates to another page. As a result, navigation is slower due to full page reloads. MPAs are built using traditional web development techniques and consist of multiple interconnected web pages.



**4. Explain the Pros and Cons of Single-Page Application.**

Pros:

Fast loading after the first request.

Smooth user experience.

Less server communication.



Cons:

Initial loading may take more time.

SEO can be difficult.

JavaScript must be enabled.



**5. Explain about React.**

React is an open-source JavaScript library developed by Facebook for building fast and interactive user interfaces using reusable components.



**6. Define Virtual DOM.**

Virtual DOM is a lightweight copy of the real DOM. React compares the Virtual DOM with the real DOM and updates only the changed elements, improving performance.



**7. Explain the Features of React**



Component-based architecture.

Virtual DOM.

JSX support.

One-way data binding.

High performance.

Reusable components.
