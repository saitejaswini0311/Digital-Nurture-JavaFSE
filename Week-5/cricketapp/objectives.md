

**1. List the features of ES6.**

ES6 introduces new JavaScript features such as `let`, `const`, arrow functions, classes, template literals, destructuring, modules, promises, spread operator, `map()`, and `set()`.



**2. Explain JavaScript `let`.**

`let` is used to declare block-scoped variables. It can be updated but cannot be redeclared within the same scope.



**3. Identify the differences between `var` and `let`.**

`var` is function-scoped and can be redeclared, whereas `let` is block-scoped and cannot be redeclared in the same scope. `let` is generally preferred because it provides better scope control.



**4. Explain JavaScript `const`.**

`const` is used to declare constants. A variable declared with `const` cannot be reassigned after initialization and is also block-scoped.



**5. Explain ES6 class fundamentals.**

An ES6 class is a blueprint for creating objects. It contains constructors, properties, and methods, making object-oriented programming easier and more organized.



**6. Explain ES6 class inheritance.**

Class inheritance allows one class to inherit the properties and methods of another class using the `extends` keyword. This promotes code reuse.



**7. Define ES6 arrow functions.**

Arrow functions provide a shorter syntax for writing functions. They use the `=>` operator and automatically inherit the `this` value from their surrounding scope.



**8. Identify `set()` and `map()`.**

Set is a collection that stores unique values without duplicates.

Map is a collection of key-value pairs and also refers to the `map()` array method, which creates a new array by applying a function to each element.
