**1. Explain React Components.**

React components are reusable building blocks of a React application. They divide the user interface into independent and manageable parts that can be reused throughout the application.



**2. Identify the differences between Components and JavaScript Functions.**

React components are used to create and display user interface elements, whereas JavaScript functions are general-purpose functions used to perform specific tasks. Components return JSX to render UI, while JavaScript functions may return any type of value.



**3. Identify the types of Components.**

&#x20;React has two types of components:

Class Components

Function Components



**4. Explain Class Component.**

A class component is a React component created using an ES6 class. It extends the `React.Component` class and uses the `render()` method to display content on the screen.



**5. Explain Function Component.**

A function component is a simple JavaScript function that returns JSX. It is easy to create and is mainly used to display user interface elements.



**6. Define Component Constructor.**

A constructor is a special method in a class component that is executed when the component is created. It is used to initialize the component's state and bind methods if required.



**7. Define `render()` Function.**

The `render()` function is a mandatory method in a class component. It returns the JSX that is displayed on the web page and updates the user interface whenever the component changes.
