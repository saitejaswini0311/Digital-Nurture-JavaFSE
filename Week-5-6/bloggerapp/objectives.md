

**1.Explain various ways of conditional rendering.**



Conditional rendering in React is used to display different content based on a condition. It can be implemented using \*\*if-else statements\*\*, \*\*ternary operators (`condition ? true : false`)\*\*, \*\*logical AND (`\&\&`) operators\*\*, or by returning different components.



**2. Explain how to render multiple components.**

Multiple components can be rendered by importing them into a parent component and including them within the JSX. This helps organize the user interface into reusable sections.



**3. Define list component.**

A list component is a React component that displays multiple items by iterating over an array of data. It is commonly implemented using the `map()` function.



**4. Explain about keys in React applications.**

Keys are unique identifiers assigned to elements in a list. They help React identify which items have changed, been added, or removed, improving rendering efficiency.



**5. Explain how to extract components with keys.**

When a list is divided into separate components, the `key` should be assigned to the component instance in the parent list. This allows React to manage each component efficiently.



**6. Explain React `map()` function.**

The `map()` function is used to iterate over an array and return a new array of React elements. It is commonly used to render lists of data dynamically in React applications.
