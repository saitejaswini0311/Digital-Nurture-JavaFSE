1. Explain React events.
React events are actions triggered by the user, such as clicking a button, typing in a text box, or submitting a form. They allow components to respond to user interactions.

2. Explain about event handlers.
Event handlers are functions that execute when an event occurs. In React, they are attached to elements using event attributes such as `onClick`, `onChange`, and `onSubmit`.

3. Define Synthetic Event.
A Synthetic Event is React's wrapper around the browser's native event. It provides a consistent event interface across different browsers and works the same way in all supported environments.

4. Identify React event naming convention.
React event names use **camelCase**. For example:

* `onClick`
* `onChange`
* `onSubmit`
* `onKeyDown`

Unlike HTML, React uses camelCase event names and passes a function as the event handler.
